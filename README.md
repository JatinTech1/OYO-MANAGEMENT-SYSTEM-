# OYO-MANAGEMENT-SYSTEM-
Developed an end-to-end OYO Management System database project to manage hotel operations, including customer details, room management, bookings, payments, and feedback records. Designed and implemented a relational database using SQL by creating tables, defining relationships, applying constraints, and inserting structured data. Performed complex SQL queries using joins, aggregations, subqueries, and data analysis techniques to generate meaningful insights and improve data management. Optimized database structure to ensure efficient storage, retrieval, and management of hotel-related information.

Skills Used: SQL, Database Design, MySQL/PostgreSQL, ER Modeling, Joins, Constraints, Data Analysis
